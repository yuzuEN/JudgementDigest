設計方向

像一份整理好的諮詢報告，不像一個儀表板

暖白紙底、深青藍主色、大字級。每個畫面只做一件事，數字一定和白話說明放在一起。使用者多半焦慮，介面要先讓人鬆一口氣，再讓人看懂。

先說人話，再放數字

每個數字都接一句「這代表什麼」。範圍永遠搭配「10 件約有 8 件」。

不做成保證

不用儀表板指針、紅綠燈、「你會贏」。機率收在「模型細節」，主畫面看真實判決的件數。

顏色各有專屬用途

橘色只給「遮名」。紫灰只給「示例資料」。結果用深靛／淺藍／斜線，加文字，不靠紅綠。
