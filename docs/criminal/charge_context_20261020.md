## 順序與觸發條件

1. 先看罪名本身。非駕駛罪仍走原本 regex；明示酒／毒、明載款別或明示混合則直接回傳，完全不以同案其他毒品字樣改寫。名稱與單一款別矛盾仍不確認。
2. 僅無明確酒／毒依據的既有駕駛類才處理上下文：分離附件、解析同法回指、移除完整法條引文，再用既有 `conviction_passages` 的法院／否定／檢方主張規則篩選。沒有擴充否定詞表。
3. 優先找駕駛罪的論罪配對及其款別；致死與重傷結果不能跨罪配對。同案多個駕駛罪須名稱精確對應，不靠整案事實共用分類。單款與名稱直接互斥時，不因另一混合群組而視為成功。
4. 單一駕駛罪可沿用法院同一行為的明示混合認定；仍未配到時，才看同句的飲酒／施用後駕車或實際酒測證據。多駕駛罪不使用未配對的一般行為敘述補推；致死／重傷的單一駕駛罪保留原有事實判斷，不能因結果字樣就一概留空。已判為另一罪的論罪句也不能再繞回事實分支採用。混合事實而無法院認定、衝突或不足均留空。
5. 正式法條仍依既有新版 → 空槽判定 → 來源篩選 → fallback → 標準化／資格檢查執行。來源及拒絕原因照常保留。

舊整格 `normalize_charges` 仍全有全無：`[不能安全駕駛動力交通工具罪,竊盜罪]` 無上下文為空；有明確第185條之3第1項第1款的法院配對時為 `[酒駕罪,竊盜罪]`。上下文補齊能避免不必要的整格空，但不足時仍會空。正式逐罪保留成功及空槽證據，罪名訓練仍要求每槽完整，法條任務仍採其獨立既有准入。
