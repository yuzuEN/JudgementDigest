# 罪名與法條標準化：未解決問題

## 法規指代詞

判決理由常以「前開條例」、「同條例」、「該條例」、「同法」代替前文已出現的完整法規名稱。它們不是正式法規名稱，也不是文字截斷。

目前 107–109 年資料中有 95 筆法條包含「前開條例」，人工檢查均指向「毒品危害防制條例」。典型原文先寫「毒品危害防制條例第2條」，下一句再寫「係犯前開條例第10條」。現行結構化規則只取含「係犯」的結論句，因此會留下「前開條例第10條」。

暫定處理：不在 `normalize.py` 猜測完整名稱，保留原始法條。未來應回到同一判決的理由文字，向前尋找最近出現的完整法規名稱；找不到時標記為 `unresolved_reference`。

## 法條的兩種層級

`法條標準鍵`保留「之N」，例如「刑法第339條之4」，供未來罪名對照使用；`法條粗分類`移除「之N、項、款」，例如「刑法第339條」。粗分類不可作為罪名對照鍵，否則刑法第185條與第185條之3等不同犯罪會被錯誤合併。

## 法規版本

「修正前刑法」與「修正後刑法」目前統一為「刑法」，但尚未另外保存行為時法、裁判時法及適用期間。遇到法律修正前後條號或構成要件不同時，仍須以原始欄位人工核對。

## 法條角色

目前尚未區分定罪法條、刑法總則、程序法、沒收及量刑法條。例如刑法第28條是共同正犯規定，刑事訴訟法第299條是程序依據，均不宜直接視為犯罪名稱的主要法條。

## 罪名粗分類

目前罪名標準化採文字型犯罪家族規則，例如酒精濃度或不能安全駕駛的不同寫法統一為「酒駕罪」，各種加重、共同或未遂詐欺統一為「詐欺罪」。任一罪名未命中規則時，該案標準化罪名留空，避免把原始長罪名誤算為標準化成功。

這一層刻意忽略部分會影響法定刑的細節，只適合分類與初步建模，不應取代原始罪名作法律判斷。未來需根據實際罪名分布擴充規則，並加入規則版本、覆蓋率及人工確認狀態。
