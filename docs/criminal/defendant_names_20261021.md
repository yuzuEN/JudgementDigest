# 被告姓名：2026-10-21

修正被告姓名紀錄計數與主文姓名匹配。基準為 `6f37fd9`，保留正式新版＋受限制 fallback、1／2／6語境修正、按需罪名上下文、Windows 修正與既有訓練准入。

## 規則及實際入口

- 被告欄僅以 `；`／`;` 分隔。空格、`‧`／`·`、頓號都留在人名內；不按長度、字元種類或是否出現在主文刪人，不去重姓名紀錄。空紀錄不計數，全空為不明。分類是**欄位紀錄數**，不是身分核實結果。
- 原始「被告／相對人」值不改寫。匹配時才對姓名與主文兩邊同樣移除空白，長姓名先試；不把空白拆成多人，也不合併不同間隔號、不還原匿名身分。
- 先用原有主文範圍及分句規則，再略過句首主刑標題／序號。僅在受判決者的句首位置（可有「被告」）依序試：**實際姓名 → 遮名／匿名代號 → 既有萃取**。遮名支援甲至癸配兩個以上○／Ｏ等記號，以及 A01／全形Ａ０１等代號，不到全文中找證人或被害人代號。
- 姓名定位成功後，只對其後文字使用既有「犯…罪」及刑度前描述規則，不再把另一個姓名路徑的結果聯集進來；省略犯／罪、同句「又犯」仍保留。「共同」等原有描述不另改標準化。
- 宣告刑前有附表引用者交回舊路徑，**附表解析、准入、全文補附表均未改**；這也保留既有附表限制，不聲稱此輪已解決附表姓名／罪名問題。
- 法條繼續走新版逐罪配對 → 空槽判定／來源篩選 → 受限制 fallback → 既有標準化／資格檢查。姓名修正沒有放寬否定、檢方主張、缺部分法條、未解回指或來源未核實的限制。
