# 已確認的論罪語境修正（2026-10-20）

本次只處理授權的 1、2、6：論罪入口、局部量刑引用、新舊法比較中的暫定候選。不恢復整案 fallback、不增加多罪補空，不修改罪名粗分類、頻率白名單、項款標準化或既有否定／檢方主張政策。

## 修改及實際作用範圍

`structure_tasks.py` 是唯一修改的正式程式。新增的 `conviction_context()` 供 `conviction_passages()`、`extract_laws()`、`laws_in_text()` 共用；正式逐罪配對、主文同子句法條與離線實驗的可接受文字因此使用相同保護。舊版 git revision、歷史 audit 快照不修改；正式 `matched_laws()` 沒有接回舊 matcher。

1. `CONCLUSION_CHARGE_RE` 的「各犯」改為 `各犯(?!行(?:時|為|[，。；、]|$))`，避免「上開各犯行時」「上開各犯行，」誤作論罪入口。不是單純 `(?!行)`：真正的「各犯行使偽造私文書罪」「各犯行求賄賂罪」必須保留。
2. 量刑判斷綁在單一法條後的明確尾句，例如「規定加重其刑」「之規定，減輕其刑」「的規定，加重被告的刑度」。只遮蔽該處引用，保留句界及其他法條，不清空整句，也不根據法律名稱／通則條號黑名單刪除。裸列刑法第11條、第47條仍保留；「加重竊盜」及法條全文「處……有期徒刑」不是排除條件。沒有宣稱此規則能去除全部一般條文。
3. 「於修正後係犯……」「修正前被告所犯為……」等局部比較試算不作最終論罪入口；遮蔽到下一逗號／句號／分號為止，避免先命中即回傳。其後明示論罪仍走既有罪名配對。「係犯修正前……」「係犯修正後……」本身都不一概排除。

新舊法處理採保守範圍：不把後面任何被告／任何罪的「應適用某條」搬來覆寫前面候選。若最後採用說明沒有足夠的同罪配對證據，保留空值。這不是通用的新舊法裁決器，也沒有新增依全文推論第8條補空的功能。

### 處理順序

沿用來源欄位分離及法名回指處理 → 遮蔽局部新舊法比較試算及明確量刑引用 → 既有句界、檢方主張／法院恢復與否定詞檢查 → 精確論罪入口 → 既有罪名與法條配對 → 原始／標準欄位及訓練資格判定。

局部遮蔽只作用於匹配文字，原始 DB 與原文證據不改寫。標準化仍只作既有輸出轉換；本輪沒有因為最後會去項款而改動原始法條，也沒有為提高填值率放寬訓練准入。

兩批固定樣本分開回放，沒有合併計算：

- reviewer 的100案來自「舊版有值、當時新版全空」2,707案。歷史14筆 raw 錯誤引用中，id132204 的第二級施用錯配是**僅項次差異1筆**；其餘**13筆為條級錯配**，分布在12案。未解決的「前揭條例」字串仍是解析／訓練資格問題，不能因項次不列本輪錯誤就直接入訓練。本輪正式 before／after 的這100案均仍全空，不能宣稱「正確率100%」。
- 新做 fallback 實驗的100案來自另外1,810個補回案件。本輪前後輸出相同：**9案條級混入／錯位、1案僅項次差異、1案只補幫助犯而缺核心法條**；其餘89案補回的核心法條有原文支持。按本次法名＋條號目標，僅項次差異那1案不計為條級錯誤，因此有90案未見新增條級錯配。這不保證法條齊全、法名字串乾淨或上游罪名槽正確。
- id53384 是額外指定邊界案例，不在新實驗的固定100案內；其第7條候選被擋下，不能把它加進分子卻沿用100的分母來宣稱錯誤率下降。

PR 檔案範圍的 **559項測試通過**（既有546＋本次13）。保留的離線實驗另有10項測試，不把未提交實驗的測試算進 PR CI 數量。測試驗證已列出的機械條件，並未證明全資料語意正確。
