# 台灣判決書論點標註手冊 v0.4

標註判決理由中「法院在做什麼」的規則。以 AI 為主要標註者，人工依線索抽查。

## v0.4 的修訂摘要

v0.3 抽查發現的問題，根源是同一個：**標籤掛在法院「準備判斷」的句子上，而不是「完成判斷」的那一句。**
大前提被標成 SUB 或 PROC，列舉證據被標成 EV，或標籤對了但引文引到列舉的部分。

| 項目 | v0.3 | v0.4 | 依據 |
|---|---|---|---|
| **RULE 規範陳述**（刑民共用） | 無 | **新增** | 只有大前提的段落佔隨機樣本 5.5%，模型三次在這些段落標出 8 種不同標籤，表示手冊沒有給大前提歸宿；法律系學生同意將大前提與涵攝分開 |
| **SUB 涵攝** | 窄定義（明示寫法） | 改為「本段完成定性」；只有大前提歸 RULE | 抽查 1249、1251：只有前提、沒有定性 |
| 規則 8 | 只陳述法條 → NONE | 分為兩種：**判決依據的條號清單 → NONE**；**陳述大前提 → RULE** | 抽查 PROC 1050、1061、1253 被規則 8 擋下，但它們是大前提，不是條號清單 |
| **規則 10：引文錨定**（新增） | 引文出自待標段落即可 | **引文必須是完成該動作的那一句** | EV 判「符合」的 21 段中，7 段（33%）引文引到列舉證據的部分 |
| **規則 11：看起來像、但不是**（新增） | 無 | 列出四種常誤導的句型 | 抽查 EV 1109、1165，SUB 1062、1231、1241 |
| EV 評價用語 | — | 補「足見、益徵、顯見、足證、經勘驗屬實」 | 抽查 1064、1145、1110 |
| PROC | — | 補「假執行之宣告與擔保」 | 模型已如此標註，抽查判為合理，但手冊未列 |
| DAM | — | 釐清：方向欄不是標註條件；扣除已受領金額是計算，不是裁量 | 抽查 1250、1107 |
| 輸出格式 | — | 新增 `analysis` 欄位：先說明法院在本段完成了什麼動作，再給標籤 | v0.3 有 4% 的回應在 JSON 前自行寫推理說明 |

**未改動的標籤**：CL、HI、BOP、EXP、UNC、ADM、EQUITY、EXO 的定義與 v0.3 相同。

## 一、研究目的與標註單位

### 研究目的

分析不同法官在認定事實、評價證據、建立法律前提、量定刑度與賠償金額時的傾向差異；
標註結果同時供平台的判決導讀使用。

遇到邊界模糊時，回到這個問題判斷：**這段文字能不能告訴我們這位法官重視什麼？**

### 法律依據

| 規定 | 對應標籤 |
|---|---|
| 民訴§222 Ⅰ 證據力評價之自由 | EV 證據評價 |
| 民訴§222 Ⅱ 損害額之酌定 | DAM 給付額酌定 |
| 民訴§222 Ⅲ 經驗法則或論理法則 | EXP 經驗論理法則 |
| 證據能力有無 | ADM 證據能力（刑事） |

### 法學三段論與標籤的對應（v0.4 新增）

| 三段論 | 法院在做什麼 | 標籤 |
|---|---|---|
| 大前提 | 陳述法律規範或其解釋 | **RULE** |
| 小前提 | 由證據認定事實 | **EV**（或 UNC：不爭執的事實） |
| 結論 | 把事實套入規範，得出該當與否 | **SUB** |
| 法律效果的裁量 | 決定刑度或金額 | **SENT**（刑事）／**DAM**（民事） |

判決常把三段論拆在相鄰的幾個段落。標註仍以段落為單位，各段標自己完成的那一步；
分析時再以（案件, 段落序號）把相鄰段落接回完整的三段論。

### 標註單位

| | 範圍 | 切分方式 |
|---|---|---|
| **民事** | 組內資料庫 `sections.court`（法院判斷段） | `civil/insights.py` 的 `_paragraphs()` |
| **刑事** | 理由全文 | 切段規則 v2；待刑事組的段落結構確定後再統一 |

標註形式為**多標籤**。少於 20 字者不標。

## 二、通用規則

### 規則 1：很多段落不含論證，但不是大多數

v0.3 試標參考值（民事隨機 200 段）：NONE 38.5%。**若 NONE 比例明顯高於 40%，請回頭檢查 PROC、UNC、RULE 是否漏標。**

### 規則 2：只標本院自己的論理

| 內容 | 標不標 |
|---|---|
| 「上訴意旨略以⋯⋯」「被告則以⋯⋯」轉述當事人主張 | NONE |
| 「證人甲證稱⋯⋯」單純轉述證詞 | NONE |
| **轉述他案的判斷**（刑事不起訴處分書、前案判決的認定）而本院未表示採用 | NONE（v0.4 新增） |
| 「惟查，原審已斟酌⋯⋯」法院對上述內容的評價 | 標 |

### 規則 3：每個標籤都要有原文依據

每標一個標籤，必須引用 10 至 60 字的原文。**引不出來就不得標。**

### 規則 4：引文必須完全出自待標段落

### 規則 5：不確定時選 NONE

### 規則 6：前置標題句與收束結論句

**前置標題句 → NONE**；**收束結論句**（「綜上」「是以」「從而」）句中重述理由者標該理由的類型，只宣告結果者 NONE。

### 規則 7：刑民分流

### 規則 8：法條的兩種寫法（v0.4 修訂）

| 寫法 | 例 | 標籤 |
|---|---|---|
| **判決依據的條號清單**：只列出本判決所依據的條號，不陳述規範內容 | 「據上論結，依民事訴訟法第 78 條、第 385 條第 1 項前段，判決如主文」「七、訴訟費用負擔之依據：民事訴訟法第 79 條」 | **NONE** |
| **陳述大前提**：寫出規範的內容或解釋，作為之後判斷的前提 | 「按損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之」「所謂即受確認判決之法律上利益，係指⋯⋯」 | **RULE** |

大前提段落同時引用判例者，加標 CL；同時說明舉證責任分配者，加標 BOP；同時說明立法理由者，加標 HI。

### 規則 9：固定套語 → NONE

「兩造其餘攻擊或防禦方法及所提證據，經本院斟酌後，認為均不足以影響本判決之結果，爰不逐一論列」這類套語標 NONE。

### 規則 10：引文必須是「完成該動作的那一句」（v0.4 新增）

引文不只要出自待標段落，還必須是**法院完成該標籤所指動作的句子**。

| 標籤 | 引文必須包含 | 不能只引 |
|---|---|---|
| EV | 法院的**評價**（堪信、足認、足見、難認、不足採⋯⋯） | 列舉證據的部分（「業據提出⋯⋯為證」「有⋯⋯在卷可稽」） |
| SUB | 法院的**定性結論**（核屬、即屬、係犯、構成、不該當⋯⋯） | 大前提或事實敘述 |
| RULE | 規範的**內容**（「按⋯⋯」「所謂⋯⋯係指」） | 只有條號 |
| DAM | 法院**決定金額**的句子（「以⋯⋯元為適當」「減輕被告賠償金額⋯⋯」） | 單純列出請求項目 |
| PROC | 法院的**程序處分**（「准予假執行」「不待其陳述逕行判決」） | 只陳述程序法條（那是 RULE） |

**例（v0.3 抽查 1051）**

> 原告主張之事實，業據提出與其所述相符之授信約定書、連帶保證書、借據⋯⋯等件為證，**堪信原告之主張為真實**。

- ✗ 引文：「業據提出與其所述相符之授信約定書、連帶保證書、借據」（列舉證據）
- ✓ 引文：「堪信原告之主張為真實」（評價）

### 規則 11：看起來像、但不是（v0.4 新增）

以下句型容易誤導，依實際功能判斷：

| 句型 | 看起來像 | 實際上 | 例（v0.3 抽查） |
|---|---|---|---|
| 「有⋯⋯在卷可稽／可佐／可憑／可資佐證」「業據提出⋯⋯為證」而**沒有**評價 | EV | 只是列舉證據 → 依段落其他內容判斷，沒有其他內容則 NONE | 1109、1165 |
| 假設或抽象規則：「倘」「如」「若」，或主詞不是本案當事人（「該第三人」「行為人」） | SUB | **RULE**（在陳述規範，不是在定性本案） | 1062 |
| 讓步句：「姑不論」「縱認」「退步言」 | SUB、EV | 法院**沒有**採為結論 → 不標該標籤 | 1231 |
| 轉述他案的判斷（不起訴處分書、前案判決） | SUB、EV | 不是本院的判斷 → NONE（規則 2） | 1241 |

## 三、決策流程

```
步驟一：這段有沒有本院自己的動作？
        ├─ 純粹轉述當事人主張、證詞或他案判斷 → NONE
        ├─ 前置標題句 → NONE
        ├─ 判決依據的條號清單（規則 8） → NONE
        ├─ 固定套語（規則 9） → NONE
        └─ 有 → 步驟二

步驟二：用一兩句話說出法院在本段完成了什麼動作（輸出的 analysis 欄位）

步驟三：依三段論判斷（可同時多標）
        ├─ 陳述規範或其解釋 → RULE
        ├─ 證據 → 事實（評價證據） → EV
        ├─ 事實 → 法律要件（本段完成定性） → SUB
        └─ 已成立的責任 → 刑度或金額 → SENT／DAM

步驟四：逐一檢視其餘標籤

步驟五：每個標籤的引文，都必須是完成該動作的那一句（規則 10）

步驟六：EV 填傾向；DAM 填方向；其他標籤留白
```

## 四、刑事標籤（10 類）

### RULE 規範陳述（v0.4 新增，刑民共用）

**定義**：法院陳述法律規範的內容或其解釋，作為之後判斷的大前提。

**標**：

- 「按⋯⋯」「次按⋯⋯」引述法條內容
- 「所謂⋯⋯係指⋯⋯」解釋法律概念
- 抽象規則的陳述：「倘有配偶之人與他人交往⋯⋯即為共同侵權行為人」（主詞不是本案當事人）
- 一般性的法律見解：「法院建立未遵指示即屬重大過失之一般性規則」

**不標**：

- 只有條號、沒有規範內容（規則 8，NONE）
- 已經把本案事實套入規範（標 SUB；若同段也陳述了規範，可同時標 RULE 與 SUB）

**正例**

> 按損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

> 確認法律關係之訴，非原告有即受確認判決之法律上利益者，不得提起之，民事訴訟法第 247 條第 1 項前段定有明文。所謂即受確認判決之法律上利益，係指⋯⋯
> → **RULE**（大前提）；同段若接著寫「故本件原告之訴有確認利益」，再加標 **PROC**

**易混淆**

- **vs PROC**：陳述程序法的規範（「原告之訴在法律上顯無理由者，法院得不經言詞辯論逕以判決駁回」）是 RULE；法院在本案**實際做出**程序處分才是 PROC。
- **vs CL**：同段引用判例時兩者都標。

> 研究意義：法官如何建立大前提（只引法條、解釋概念、援引判例或立法目的），
> 是 Koref et al. 分析司法形式主義的核心。RULE 是補上「法律解釋方法」這個缺口的第一步。

### SUB 涵攝（v0.4 修訂，刑民共用）

**定義**：法院在**本段**將本案事實套入法律要件，**完成**該當或不該當的定性。推論方向是「事實 → 法律要件」。

**判準**：本段必須出現定性的結論。只有大前提、結論在後段者，本段標 RULE，不標 SUB。

**常見寫法**：「核被告所為，係犯⋯⋯罪」、核屬／即屬／自屬／應屬⋯⋯、構成⋯⋯、該當／不該當⋯⋯要件、「已無法律上原因⋯⋯並致原告受有損害」（逐一套用要件）

**不標**：只有大前提（RULE）；讓步句與他案判斷（規則 11）；證據可不可信的判斷（EV）。

**正例**

> 核被告所為，均係犯刑法第 339 條第 1 項之詐欺取財罪

> 被告無法律上原因而獲債務減免之利益，核屬給付型不當得利（v0.3 抽查 1236）

**反例（v0.3 抽查 1249，只有前提 → RULE）**

> 仍須符合附表項次 1 各項要件，始有附表項次 1 各等級之適用

### SENT 量刑審酌

**定義**：法院就刑度的裁量理由，含加重、減輕、緩刑、沒收。

**標**：刑法§57 各款情狀、犯後態度、和解賠償、前科累犯、自白減刑、減刑要件的適用與否。

**不標**：轉述當事人請求從輕量刑；只陳述沒收或減刑的法條內容（RULE）。

**易混淆**：量刑論述中的「比例原則」「依職權自由裁量」一律標 SENT；減刑要件判斷標 SENT，新舊法比較標 HI。

### EV 證據評價（v0.4 修訂）

**定義**：法院就特定證據**表示採信或不採信**，並據以認定事實。推論方向是「證據 → 事實」。

**評價用語**：

| 類別 | 用語 |
|---|---|
| 採信 | 堪信、可採、足認、堪認、應堪認定、核與⋯⋯相符、互核一致、非虛、可資佐證、**足見、益徵、顯見、足證、經勘驗屬實** |
| 不採信 | 不足採、無可採、不可採、難認、尚難、無足取、顯有疑義、難以採信、前後不一 |
| 證明不足 | 尚無法證明、不能證明、查無其他積極證據、罪證有疑 |

**引文**：必須包含上述評價（規則 10）。

**不標**：只列舉卷證而沒有評價（規則 11）；證據能力（ADM）；事實套入法律要件（SUB）。

**屬性欄位**：`傾向 = 有利被告／不利被告／中性`

### CL 判例援引

**定義**：引用法院過去的具體裁判作為依據。**標**：裁判字號、「判決意旨參照」、「判例」、「大法庭裁定」。**不標**：引用法條本身。

### PROC 程序處理

**定義**：訴訟要件、上訴合法性、審判範圍等程序事項的**處分**。

**標**：上訴程式是否合法、逾期、補正、一部上訴範圍的確定、不另為無罪諭知、附帶民訴的程序前提、程序上駁回、不待其陳述逕行判決。

**不標**：實體上的無罪認定（EV）；論罪（SUB）；只陳述程序法的規範內容（RULE）。

### HI 歷史解釋

**定義**：援引立法理由、修法沿革、立法者意旨解釋法律；新舊法比較。

### ADM 證據能力

**定義**：某項證據得否作為證據的判斷。「對證據能力不爭執／無意見」標 ADM，不標 UNC。

### UNC 不爭執事項

**定義**：當事人不爭執，或依法無須證明，法院逕採為認定基礎的**事實**。

### EXP 經驗論理法則

**定義**：法院**明示援引**經驗法則、論理法則或常情，或明示表述證明度標準。

### NONE 無論證

轉述、前置標題句、只宣告結果的收束句、判決依據的條號清單（規則 8）、固定套語（規則 9）、格式文字。

## 五、民事標籤（11 類）

RULE、SUB、EV、CL、EXP 定義與刑事相同。EV 的傾向欄位為 `有利原告／有利被告／中性`。

### DAM 給付額酌定（v0.4 釐清）

**定義**：在責任已成立的前提下，法院就**賠償或給付金額**所為的裁量理由。

**標**：慰撫金之核定（民法§195）、過失相抵（§217）、損害額之酌定（民訴§222 Ⅱ）、違約金酌減（§252）、以公平原則決定金額。

**v0.4 釐清**：

- **方向欄位不是標註條件。** 慰撫金的審酌即使最後全額准許，也標 DAM，方向填「全額准許」（v0.3 抽查 1250）。
- **扣除已受領的金額是計算，不是裁量**（「應自請求數額內扣除已受領之 50 萬元」）→ 不標 DAM（v0.3 抽查 1107）。
- 只陳述§217、§195 的規範內容而未適用 → RULE。

**屬性欄位**：`方向 = 酌減／全額准許／不明`

### UNC 不爭執事項（民事）

## 七、驗證方式

| 層次 | 做法 | 能證明 |
|---|---|---|
| 沿用 | 定義未改的標籤（CL、HI、BOP、EXP、UNC、ADM、EQUITY、EXO）沿用先前與法律系學生比對的結果 | 效度 |
| 線索抽查 | RULE、SUB、EV、PROC、DAM 各抽 25 段，人工判斷標籤與引文是否符合手冊 | 精確度、引文正確率 |
| 引文自動檢查 | 程式檢查 EV、SUB 等的引文是否含動作用語（規則 10） | 引文錨定的符合率 |
| 自身一致性 | 每段標三次 | 穩定度 |

**v0.4 的驗證必須使用新抽的段落**，不得與 v0.3 的 290 段（及其所屬判決）重疊：
v0.4 的規則由那批段落的抽查結果導出，以同一批驗證會有樂觀偏誤。

## 八、已知限制

1. **大多數修訂未經法律專業人員審閱。** RULE 的新增已徵詢法律系學生同意；規則 10、11 與 DAM 的釐清由非法律背景的研究者依抽查結果決定。
2. **EV 的效度仍未確認。** v0.3 抽查的 EV 精確度為 0.8750（21/24），但引文錯誤率 33%。
3. **法律專業的驗證只來自一位法律系學生，共 77 段。**
4. **段落切分會截斷三段論。** v0.3 隨機樣本中 16.5% 的段落是長段在 400 字處切開的後半。標註單位與判決導讀一致，不另外合併；分析時以段落序號接回。
5. **RULE 尚未細分解釋方法。** 文義、體系、目的解釋目前都標 RULE，未來可再分。
6. **語料偏斜。** 民事為組內資料庫（一審、對審），刑事以二審為主。
